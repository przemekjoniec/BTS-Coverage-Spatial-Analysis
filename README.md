# 5G Network (BTS) Coverage Simulation and Optimization - Spatial GIS Analysis

## 📌 Project Objective
The primary objective of this project is to conduct an advanced spatial analysis to identify "white spots" (areas lacking optimal radio signal coverage) and determine the most business-optimal location for a new 5G Base Transceiver Station (BTS). The project simulates a real-world radio network planning (RF Planning) process, utilizing demand analysis generated by local infrastructure based on reference data. The analytical area covers the city of Limanowa.

## 🗄️ Data Sources
The project integrates official state spatial registries and simulated data:
* **BDOT10k (Topographic Object Database):** Downloaded from the Head Office of Geodesy and Cartography (GUGiK) servers. The vector layer `BUBD_A` (Buildings and Structures) was used for urban fabric analysis.
* **DEM (Digital Elevation Model):** High-resolution raster data (5x5m grid) from Geoportal, used to assess terrain topography and radio visibility (Line of Sight).
* **PRG (National Register of Boundaries):** Used to precisely clip (mask) the working area to the municipal boundaries.
* **BTS Infrastructure (Simulated Data):** A custom point feature class created to represent existing base stations, localized based on reference data verification.

## ⚙️ Methodology and Data Processing
The analysis was conducted in the **ArcGIS Pro** environment and consisted of the following engineering stages:

1.  **Data Extraction and Preparation:**
    * Extraction of building footprints exclusively for the Limanowa city area (*Select By Location* tool - Relationship: Intersect).
    * Calculation of the actual geometric area for each polygon in square meters into a newly created `Pole_Pow` (Area) field (*Calculate Geometry*).

2.  **Network Demand Modeling:**
    * Business classification of buildings was introduced based on their general function (attribute `FOBUD`).
    * Network load weights (`Waga_Funkcji`) were assigned depending on the anticipated telecommunications traffic: 
        * **10** - Critical and commercial facilities (offices, education, hospitals, retail).
        * **5** - Facilities generating stable traffic (residential buildings, transport).
        * **1** - Low-traffic/not generating demand facilities .

3.  **TotalDemand Indicator Calculation:**
    * For each building in the attribute table, the resultant network demand indicator was calculated by multiplying the assigned business weight by the physical size of the facility: `TotalDemand = Waga_Funkcji * Pole_Pow`.

4.  **Coverage Analysis and White Spot Detection:**
    * A simulated area of excellent high-frequency signal coverage (500m radius) was generated around existing BTS stations (*Buffer* tool with *Dissolve* option).
    * An inverted spatial selection was performed, isolating buildings with a high `TotalDemand` indicator located outside of the current coverage.

## 📊 Results and Conclusions (Site Hunting)
The spatial selection results and attribute table sorting clearly indicated the main network deficit area. The absolute leader in terms of data transfer demand turned out to be the **County Hospital**, achieving a `TotalDemand` indicator of over **25,000 units** (significantly outperforming neighboring retail and industrial facilities). The hospital, as a critical facility requiring high bandwidth (telemedicine, transfer of large diagnostic files), provides a perfect business justification (Business Case) for a new investment.

**Recommended Investment:**
Instead of a costly construction of a new ground-based tower (Greenfield) on the surrounding hills identified from the DEM, an attribute verification of the building itself was conducted. Based on BDOT10k data (`LICZ_KONDY` = 5), it was established that the hospital building is a dominant, tall structure in the area. 

A **Rooftop** base station installation (on the hospital roof) is proposed. This solution:
* Instantly resolves the "white spot" problem for the most demanding client in the region.
* Ensures excellent signal propagation from a high altitude to surrounding residential areas (visible in the generated optimization buffer).
* Significantly reduces CAPEX (capital expenditures) by eliminating the need to build foundations and lease new land.
